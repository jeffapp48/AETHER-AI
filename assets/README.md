# Biblioteca de Assets

Guarde aqui materiais reutilizáveis para evitar recriação e desperdício de tokens.

## Categorias

- `templates/`: modelos de documentos e entregas.
- `workflows/`: fluxos de trabalho validados.
- `knowledge/`: conhecimento permanente e instruções de domínio.
- `prompts/`: prompts compilados prontos para uso.

Antes de criar algo novo, verifique se já existe um asset semelhante.
