# Prompt de Uso — MVP GBP

## Arquivos necessários

Carregue somente:

1. `agents/editor-chefe-gbp.md`
2. `assets/MATRIZ-AUTORIDADE-SISTEMA-FISIO.md`
3. `templates/PLANO-SEMANAL-GBP.md`
4. histórico de publicações, quando existir;
5. catálogo de fotos e vídeos, quando estiver pronto.

## Comando padrão

```text
Use o Editor-Chefe GBP.

Crie as três postagens desta semana para o Perfil da Empresa no Google da Sistema Fisio.

Consulte a Matriz de Autoridade e siga o template do Plano Semanal GBP.
Não invente casos clínicos, resultados ou mídias disponíveis.
Quando o catálogo de mídia não estiver disponível, descreva exatamente qual foto ou vídeo Jefferson deve selecionar.
Entregue o plano e os três textos completos, prontos para aprovação manual.
```

## Comando para planejar sem redigir

```text
Use o Editor-Chefe GBP.
Planeje apenas os três temas da próxima semana.
Não redija os textos ainda.
Informe tema, objetivo, serviço, palavra-chave, região, mídia e CTA.
```

## Comando após aprovação do plano

```text
O plano semanal foi aprovado.
Agora redija as três publicações completas, seguindo exatamente os temas aprovados e o template do Plano Semanal GBP.
```

## Resultado esperado

O sistema deve entregar três publicações contendo tema, objetivo, serviço, palavra-chave principal, termos relacionados, localização natural, mídia sugerida, texto final, CTA, nome do arquivo e checklist de aprovação.

## Limitação atual

O MVP não publica automaticamente e ainda não seleciona arquivos diretamente do Google Drive. Jefferson aprova, escolhe a mídia correspondente e publica manualmente.
