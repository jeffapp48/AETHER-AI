# Projetos

Cada tarefa maior deve ter uma pasta própria contendo somente o contexto necessário.

## Estrutura sugerida

```text
projects/nome-do-projeto/
├── BRIEFING.md
├── PLANO.md
├── ENTREGAS.md
└── DECISOES.md
```

Não copie conversas completas. Registre apenas requisitos, decisões e entregas aprovadas.
